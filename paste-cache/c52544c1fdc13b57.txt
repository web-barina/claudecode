# デザイン・レイアウト追加指示

今回の情報設計変更に合わせて、レイアウトも見直してください。

現在のサイトは左寄せのコンテンツが続くことで、視線の起点が固定され、セクションによっては不自然・単調に見える。

そのため、**各セクションの内容に応じて、適宜センター寄せを取り入れる。**

ただし、すべてを中央寄せにするのではなく、

* 説明・読み物 → 左寄せ
* コンセプト・短いメッセージ → 中央寄せ
* 数字・キーワード・図解 → 中央寄せ
* フロー・タイムライン → 中央を軸に構成
* 長文 → 左寄せ

というルールで使い分ける。

---

## 1. FIRST VIEW

基本的に中央寄せ。

メインコピー、

「整理して、つないで、
ちゃんと前に進める。」

を画面中央で強く見せる。

肩書きや名前も中央寄せ。

ファーストビューでは「文章を読む」より、
**コピーを視覚的に受け取る**ことを優先する。

---

## 2. ABOUT

中央寄せを基本とする。

特に、

**教える仕事から、
つなぐ仕事へ。**

というメッセージは中央寄せ。

EDUCATION → WEB DIRECTOR の変換図も、
画面中央を軸に配置する。

比較表や説明文を横幅いっぱいに広げない。

「教員経験→Webディレクション」の関係を、
中央にまとまった1つのビジュアルとして見せる。

---

## 3. WHAT I DO

セクションタイトルとリードコピーは中央寄せ。

5つの仕事内容は、
カードを均等に並べる。

デスクトップ：

[ 01 ] [ 02 ] [ 03 ] [ 04 ] [ 05 ]

または、

[ 01 ] [ 02 ] [ 03 ]
[ 04 ] [ 05 ]

など、画面幅に応じて自然に調整する。

各カード内の、

* 番号
* 英語ラベル
* 日本語タイトル

は中央寄せを基本とする。

説明文が2行以上になる場合は、
読みやすさを優先して左寄せにしてもよい。

---

## 4. FOR CLIENTS

ここは特に中央寄せを積極的に使う。

見出し：

**「何を相談したらいいかわからない」
からでも大丈夫です。**

を中央寄せ。

その下の、

TALK
↓
SORT
↓
MAKE
↓
RELEASE

も中央を軸にした縦方向のフローにする。

スマートフォンでは特に、
中央寄せの縦フローが自然に見えるようにする。

最後の、

**Webに詳しくなくても大丈夫。**

という安心感を伝えるコピーも中央寄せ。

---

## 5. FOR PRODUCTION PARTNERS

見出しは中央寄せ。

CLIENT
↓
WEB DIRECTOR
↓
DESIGNER / CODER

の関係図も中央寄せ。

特に「WEB DIRECTOR」を視覚的な中心に置く。

図の下に置く短い説明文も、
1〜2行なら中央寄せ。

長くなった場合のみ左寄せ。

## 6. WORKS

ここは作品画像を主役にするため、
セクションタイトルと導入コピーは中央寄せ。

作品カード自体は、
画像・タイトル・ROLEなどの情報量に応じて左寄せでもよい。

つまり、

**セクション導入＝中央**
**作品情報＝左寄せ**

とする。

見出し：

一緒に進めていきます。**

を中央寄せ。

## 9. NOW & NEXT

# 全体のレイアウトルール

サイト全体を「全部左寄せ」または「全部中央寄せ」にしない。

以下を基本ルールとする。

### CENTER

* ファーストビュー
* セクションタイトル
* 短いキャッチコピー
* 数字
* キーワード
* 図解
* フロー
* タイムライン
* CTA
* 短い補足文

### LEFT

* 3行以上の説明文
* 長めの文章
* WORKSの詳細情報
* 読みやすさを優先するコンテンツ

---

# 余白について

中央寄せにするだけでなく、
**左右の余白をしっかり取る。**

特にデスクトップでは、
コンテンツを画面幅いっぱいに広げない。

max-widthを適切に設定し、
中央にコンテンツのまとまりを作る。

例：

* 短いテキスト：max-width 600〜700px程度
* 説明文：max-width 700〜800px程度
* カードグリッド：max-width 1100〜1200px程度

数値は現在のデザインシステムとの整合性を見て調整する。

---

# 重要

「中央寄せ＝全部text-align:center」にしない。

中央寄せにした結果、長文が読みにくくなる場合は左寄せに戻す。

目的は、

**中央に揃えることではなく、
セクションごとに視覚的な重心をつくること。**

各セクションをスクロールしたときに、

「ここはメッセージ」
「ここは仕事内容」
「ここは図解」
「ここは実績」
「ここは問い合わせ」

と視覚的に切り替わるようにする。

---

# 最終確認

PCだけでなくスマートフォンでも確認する。

特に、

* 見出しが不自然に改行されない
* 中央寄せの長文が読みにくくならない
* カードの高さが極端にバラつかない
* 図解が画面からはみ出さない
* CTAが視線の中心に入る
* セクション間の余白が均一すぎて単調にならない

ことを確認する。

**「適宜中央寄せ」＝セクションごとに視線の中心を設計する、という意味で実装すること。**
