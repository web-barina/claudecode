WHAT I DO

Web制作を、
「つくる」だけで終わらせない。

  1. 01

    REQUIREMENT DEFINITION

    要件整理

    「何をつくるか」だけではなく、
    「なぜつくるのか」を整理します。

  2. 02

    DIRECTION

    Webディレクション

    クライアントの要望を整理し、
    デザイナーやコーダーに伝わる形へ。

  3. 03

    PROJECT MANAGEMENT

    進行管理

    スケジュールやタスク、
    確認事項を整理しながら進行します。

  4. 04

    CLIENT COMMUNICATION

    クライアント対応

    曖昧なご要望も、一つずつ整理して、
    具体的な制作内容へ落とし込みます。

  5. 05

    QUALITY CONTROL

    品質管理

    デザインや実装のチェック、
    ブラウザチェック、修正確認など、
    公開前の品質まで確認します。

STRENGTH

私が大切にしている、3つのこと。

01

「なんとなく」を
そのままにしない。

「こんな感じにしたい」
「もう少し見やすくしたい」

そんな曖昧な言葉の中には、
本当の課題が隠れていることがあります。

その背景や目的を確認しながら、
言葉になっていない部分まで整理します。

02

伝わる指示に
変換する。

クライアントの言葉をそのまま伝えるだけでは、
制作はスムーズに進みません。

誰が見ても判断しやすいように、
必要な情報を整理し、
具体的な指示へ変換します。

03

チームで、
ちゃんと前に進める。

Web制作は、
一人ですべてを完結する仕事ではありません。

クライアント、デザイナー、コーダー、
それぞれの役割を理解しながら、
お互いが動きやすい状態をつくります。

PROCESS

制作を、
ひとつずつ前に進めていく。

  1. 01

    HEARING

    ヒアリング

    目的や課題、
    実現したいことを整理します。

  2. 02

    PLANNING

    情報整理・設計

    必要な情報を整理し、
    サイト構成やページの方向性を考えます。

  3. 03

    DIRECTION

    制作ディレクション

    デザイナー・コーダーと連携し、
    制作を進めます。

  4. 04

    CHECK

    確認・品質管理

    デザインや実装を確認し、
    必要な修正を整理します。

  5. 05

    RELEASE

    公開

    最後まで確認を行い、
    公開までプロジェクトを進めます。
