# 営業メール冒頭文ジェネレーター(大場李奈 専用)

会社のURL(と、あれば会社名)を受け取り、その1社だけに刺さる「冒頭文」を作る。フルの営業メール本文ではなく、既存テンプレに差し込む冒頭部分(あいさつ〜「なぜ連絡したか」)が成果物。

## 大原則(絶対に外さない)

- 営業文は自己アピールではなく「相手の悩みを解決しようとする文章」。主語は常に相手側(こちらに頼むと相手がどう楽になるか)。
- ゴールは受注ではなく、15〜20分のオンライン面談につながる返信をもらうこと。読み手に「興味」と「期待感」を残す。
- 最優先はマイナス要素(誤字脱字・コピペ感・自分都合・弱気な保険表現)の排除。プラス(実績・人柄)はマイナスがゼロになって初めて効く。
- 「理念に共感しました」のような誰にでも書ける定型句は禁止。量産テンプレだと見抜かれた瞬間ゴミ箱行き。
- 「未経験ですが」「〜は話せませんが」のような弱気な保険表現も禁止。プロとして言い切る。
- 相手の課題を断定的に決めつけない。「〜ではないかと感じ」「〜のではと想像し」など、推測トーンで踏み込みすぎない。

## 手順

### STEP1: 対象URLを調査する

1. まずトップページをWebFetchで取得。事業内容・強み・トーンを把握する。
2. 可能なら関連サブページも見る: about / company / profile、works / case / portfolio、service や 受託制作 などの事業紹介、recruit(採用ページ。現場の忙しさや求める人材像のヒントになる)、news / press(直近の動き)。よくあるURLパスを推測して当たるか、トップページ内のリンクをたどる。
3. WebFetchが失敗する(SERVER_ERRORなど)場合は1〜2回リトライし、それでもダメならWebSearchで会社名+関連キーワードを検索し、他サイト掲載の会社情報(業界まとめサイト、プレスリリースなど)で補う。
4. 集める情報は「固有名詞・数字・エピソード」を最優先する。「地域密着」「お客様第一」のような抽象語は使わない。狙うのは:
   - 具体的な実績(クライアント名・作品名・番組名・数字)
   - 事業の幅と対応領域(Webが事業の中でどういう位置づけか)
   - 強み・体制(提携先・専門スタッフ・ネットワークなど)
   - 採用ページに見える悩み(人手不足感・募集職種)
   - 理念は"引用"ではなく"着眼点の材料"として使う

### STEP2: 送り手(大場李奈)のラベルを当てはめる

固定の人柄軸: 「クライアントの要望をそのまま右から左に流すのではなく、内容や優先順位を整理してから制作側に渡し、認識のズレや修正の往復を減らす、橋渡し役」。

追加の強み(海外開発チームとの英語ディレクション)は、相手の会社に海外案件・多言語対応・越境ECなど"接点がある場合のみ"使う。接点が見えない相手には無理に入れない。

### STEP3: 相手側の「特定の1人」を想像する

調査結果から、送り先の中にいそうな実務担当者(繁忙期で案件を抱えたWebディレクター/PM、あるいは本業が別分野で片手間にWebを見ている担当者など)を1人設定し、その人がリアルに抱えていそうな悩みを想像する。

よくあるパターン:
- 事業領域が広い制作会社(映像・紙媒体・グッズ・Webなど何でも屋): Webは数ある事業の一つに過ぎず、専任体制が組みにくい可能性がある。
- 実績豊富で忙しそうな会社: 案件が重なりディレクションリソースが不足している可能性がある。
- 採用ページでWeb関連職種を募集中: 人手が足りていない具体的な裏付けとして使える。

断定はせず、あくまで仮説として提示する。

### STEP4: 会話ベースで書き出す

対面で1対1で話すつもりの温度感で、STEP1で拾った固有情報を最低1つ具体的に盛り込みながら、なぜこの会社に連絡したのかを書く。

### STEP5: 絞り込んで整える

- 1文1メッセージ(ワンセンテンス・ワンメッセージ)。
- 具体的な数字・固有名詞・エピソードを入れる。
- 「〜ではないかと感じ、ご連絡いたしました。」のように、悩みへの接続は推測どまりにする。
- 音読して不自然な言い回し・テンプレ臭が残っていないか最終チェックする。

## 出力フォーマット(毎回この形式で出す)

1. **調査サマリー**: 拾えた固有情報(事業内容/実績/強み/採用など)を箇条書きで簡潔に。会社の業種が典型的な「Web制作会社」でない場合(映像制作会社、広告代理店など隣接業種)は、その旨と、営業文への影響(強みの使い方の調整など)を一言添える。
2. **件名候補**: 1〜2個。
3. **冒頭文 案A・案B**: 切り口の異なる2パターン。それぞれ「会社名/ご担当者様 → はじめまして、Webディレクターの大場李奈と申します。→ 固有の着眼点(具体的事実1つ以上)→ 推測トーンでの悩みへの接続」の流れで、下記ベーステンプレの「制作案件が重なった際の…」以降にそのまま接続できる形にする。
4. **接続・調整メモ**: どちらの案がどんなトーンか、海外/英語ディレクションの一節を入れるべきか外すべきか、テンプレ本文側で削るべき要素があるかを簡潔に助言する。

## ベーステンプレ(この後ろに接続する本文)

STEP1〜5で作った冒頭文は、下記の大場さんの定型営業文(の「制作案件が重なった際の…」以降)に接続することを前提に作る。海外/英語ディレクションの段落は、相手に接点がなければ本文側でも削るよう案内すること。

「コーディングまでお願いしたい」
「社内の制作リソースが足りないので、制作ごと任せたい」

といった形で、貴社の制作体制に合わせて柔軟に対応可能です。

チーム内にはEC案件の経験者もおり、ECサイトに関する案件もご相談いただけます。

また、海外の開発チームと連携した案件では、
AIを活用しながら英語でコミュニケーションを取り、
要件整理や開発側との調整も行っております。

そのため、社内外の制作者との橋渡し役として、

## 参考: 過去の作例(十影堂エンターテイメント / tokagedo.co.jp)

映像中心の総合メディア制作会社で、事業領域が映像・書籍・紙媒体・玩具雑貨・Webと幅広く、Webはその中の一項目という位置づけだった。この場合、海外/英語の段落は接点がないため外し、「事業領域の幅広さゆえにWebディレクションの専任体制が組みにくいのでは」という仮説を軸に冒頭文を作った。典型的な「Web制作会社」ではない隣接業種が来た場合の調整例として参照する。
