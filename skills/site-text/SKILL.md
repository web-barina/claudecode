# site-text：西川社長FBチェッカー

西川社長への提出前に、コピー・構成・テキストを事前チェックするためのスキル。
過去のFBパターンをもとに、指摘が来る前に自分でつぶす。

---

## タスク別の動き方

**A. チェック依頼**（「社長に見せる前に確認して」など）
→ 下記の「社長FBパターン」と「チェックリスト」に照らして評価し、以下フォーマットで出力：

```
## 社長FBチェック結果

### ✅ クリアしている点

### ⚠️ 要修正の点
（どのFBパターンに該当するかも明記）

### 🔧 修正提案
修正前：
修正後：
修正理由：

### 📋 提出前にクライアント確認が必要な事項
```

**B. コピー新規作成・改善**
→ 「OKパターン」「NGワード」「コピー構造」を参照して2〜3案作成。
→ 各案に「なぜその表現にしたか（30秒で説明できる理由）」を添える。

**C. 社長への提出物作成**
→ 以下フォーマットで出力：

```
【訴求設計】
ターゲット：〇〇な状態にある〇〇
ニーズ：〇〇したい／〇〇という不安を解消したい
訴求軸：〇〇（固有の根拠）

【コピー案】
案A：
案B：
案C：

【修正意図（ディレクターメモ）】
〇〇という表現から〇〇に変えた理由：
```

## 社長FBパターン（過去の指摘まとめ）

### ① ありきたり・テンプレート感がある（最頻出）

**指摘されやすい表現**
- 「さまざまなお悩み・症状に対応しております」→ どこにでも書いてある
- 「1つ1つの施術にまごころをこめて〜」→ ポリシー的でふわっとしている
- 「お気軽にご相談ください」→ 軽すぎる・抽象的
- 「皆様から届いた喜びのメッセージ」→ 感情的高揚が強すぎてトーンがずれる
- 「皆様のリアルな変化をご覧ください」→ テンプレ感が強い

**対処**：「誰にでも当てはまる」表現を避け、そのクライアント固有の言葉・シーン・行動に置き換える。

---

### ② 強みの説明になっている（ユーザー視点が抜けている）

**社長の言葉**
>「強みを出すだけだとユーザーからすると魅力的に感じにくいので、こういう層のターゲットで、こういうニーズが強いと思うからこの訴求に、みたいなユーザーニーズと照らした意図が欲しいです」

**対処**：以下の3点をセットで考えてからコピーを書く。
1. ターゲット層の定義（誰に向けているか）
2. そのターゲットの心理状態・ニーズの言語化
3. 強みがなぜそのユーザーに刺さるのかの論理

---

### ③ LPナイズの解釈ずれ

「LPナイズ」= 感情導線を設計すること。コピー単体を送るだけではNG。

**正しい提出セット**
1. LPナイズをどう解釈したか
2. ターゲット定義と心理状態
3. その訴求を選んだ理由（なぜユーザーに刺さるか）

---

### ④ 独自要素・根拠が入っていない

**社長の言葉**
>「オーダーメードや根本解決だとどこでも言える要素な気がしていて。根拠となる独自要素を入れられないでしょうか？」

**対処**：「オーダーメード」「根本改善」は他社も使っているため差別化にならない。
クライアント固有の数字・プロセス・実績を根拠として必ず入れる。

---

### ⑤ トーン：体言止めより寄り添い型

強く言い切る体言止めより、語りかけ・寄り添う表現が合っている。
「問いかけ → 共感 → 解決提示」の流れが◎。

---

## 正解のコピー構造

```
[共感：なぜ良くならなかったか]
　　↓
[疑問の解消：原因が人それぞれ違う]
　　↓
[強みの根拠：クライアント固有の何か]
```

広告ユーザーの心理：複数社を比較済みで不信感が高い状態で来る。「また同じことを言われるんじゃないか」という懐疑心がある。先に共感が来ないと、強みの訴求が届かない。

## チェックリスト

### 表現チェック
- [ ] 「皆様」「お気軽に」「さまざまな」「丁寧に」などの汎用語を使っていないか
- [ ] 「〜を目指します」「〜できます」など弱い・受け身の表現になっていないか
- [ ] 根拠なく「オーダーメード」「根本改善」が使われていないか
- [ ] 感情的高揚が強すぎるテンプレ語（「喜びのメッセージ」「リアルな変化」等）が入っていないか
- [ ] 医療広告NGワード（完治・治す・予防医療・改善保証）が入っていないか

### 設計チェック
- [ ] ターゲット（誰に向けたコピーか）を言語化できているか
- [ ] そのターゲットの心理状態・ニーズを説明できるか
- [ ] 共感 → 疑問解消 → 差別化の感情導線になっているか
- [ ] クライアント固有の根拠（数字・プロセス・実績）が入っているか
- [ ] 「なぜその表現にしたか」を30秒で説明できるか

### 提出物チェック
- [ ] コピー案単体でなく、ターゲット定義＋訴求意図もセットで送っているか
- [ ] 修正前 → 修正後の比較とディレクターメモをつけているか
- [ ] 2〜3案のバリエーションを出しているか

## NGワード一覧

| NG表現 | 理由 |
|---|---|
| 「皆様」「さまざまな」「丁寧に」 | 汎用すぎてどこにでも使える |
| 「お気軽にご相談ください」 | 軽すぎ・抽象的 |
| 「〜を目指します」「〜できます」 | 弱い・受け身 |
| 「オーダーメード」単体 | 根拠がないと他社と差別化できない |
| 「根本改善」「根本解決」単体 | 同上 |
| 「喜びのメッセージ」「リアルな変化」 | テンプレ感・感情的高揚が強すぎる |
| No.1訴求（注釈なし） | 景表法リスク |
| 完治・治す・予防医療・改善保証 | 医療広告NGワード |
