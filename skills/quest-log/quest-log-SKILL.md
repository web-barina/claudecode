## quest-log

`daily-report` が出力した日報を、エナガ・クエスト（キャラ育成アプリ）に入れる形に変換する。

## 手順

1. 直前のセッションで `daily-report` が出力した日報を参照する。日報が見つからない場合は「先に /daily-report を実行してください」と表示して終了する。
2. 日報から次の値を抽出する。
   - **受注額（万円）**：「✅ 本日の進捗・結果」内で受注・成約・発注確定に触れている金額。確定していない見積提出・提案中はカウントしない。複数あれば合算する。金額の記載がなければ 0。
   - **完了タスク数**：「✅ 本日の進捗・結果」の箇条書きのうち、完了しているものの数。
   - **稼働時間**：「⏱ 稼働時間と業務の棚卸し」から。未記入なら 0。
   - **体現数**：「✅ 今日体現できたこと」の箇条書きの数。
   - **ズレ数**：「⚠️ ズレていたこと」の箇条書きの数。「特になし」なら 0。
3. 下記フォーマットで出力する。

## 出力フォーマット

```
🐦 QUEST LOG｜{今日の日付}

受注額：{n} 万円
完了タスク：{n} 件
稼働時間：{n} h
体現：{n} ／ ズレ：{n}

獲得予定EXP：{受注額×10 + 20 + タスク数×5 + 体現数×15}
```

そのあとに、日報本文の「✅ 今日体現できたこと」「⚠️ ズレていたこと」のセクションを、
見出しごとそのままコードブロックで再掲する（アプリの本文欄に貼るため）。

## 注意事項

- 金額は「万円」単位に揃える。「35万」「350,000円」どちらの表記も 35 として扱う。
- 受注かどうか迷う場合は 0 にせず、ユーザーに一度だけ確認する。
- 評価やアドバイスはここでは書かない。数値の切り出しだけを行う。
