# 受注成功事例ナレッジ

制作会社・フリーランスコミュニティの受注報告から抽出した成功パターン集。
面談準備・提案・クライアントワークの参考にする。

## 受注事例一覧

### 案件1：WordPress 2ページ、特急対応
- **受注額**：152,350円（特急料金込み）
- **経緯**：Indeed営業→リソース不足の返信→即面談→当日午前中に見積提出→受注
- **決め手**：
  - 困っているタイミングに即レスで面談を打診できた
  - 短納期でも「まず検討する」と覚悟を決めた
  - パートナーに相談してから自信を持って回答した
  - 連絡可否・直通電話番号を面談中に確認しておいた
- **学び**：相手のお困りごとが明確なら、そこに対してまず不安を解消する動きをする。自信がない場合は一旦持ち帰って相談してから回答する方が、相手にも自信を持って提案できる。

### 案件2：WordPress 620ページ（大型）
- **受注額**：3,427,710円
- **経緯**：継続案件の制作会社から6月相談→実現方法の調査・検討（30〜40時間投下）→正式受注
- **決め手**：
  - 1月からの案件対応の積み重ねで信頼を得ていた
  - 「できます」「大丈夫です」という言葉を選んで使った
  - 社内の「フリーに任せて大丈夫か？」という声に対して説明書を作成して納得してもらった
  - こちらから提案型でクライアントワークを行っていた
- **学び**：先にギブすれば返ってくる。受注前の調査・検討への投下は怖いが、丁寧に対応していくことで信頼に変わる。

### 案件3：デモサイト差し替え作業（0→1達成）
- **受注額**：10,000円（後に20,000円へ倍増）
- **経緯**：お盆期間中も稼働している会社にメール→HPのエラー箇所を冒頭文に記載→即お礼の返信+案件相談
- **決め手**：
  - HPのエラーに気づいてそれを冒頭文に入れた（テンプレでは気づけなかった）
  - お盆休みでも積極的にメールを送った
  - 不明点はすぐにメンバーに相談した
- **2件目受注の決め手**（倍額）：
  - 不明点はすぐに質問した（質問の観点が的を射ていると評価された）
  - 進捗をこまめに報告した
  - しばらく返信がない時はこちらから状況確認した
- **学び**：冒頭文に向き合うことでHPにも向き合える。クライアントワークをあたり前にやっていれば喜んでもらえる。

## 成功パターン横断まとめ

### 受注に繋がる行動ベスト
1. **即レス（5分以内が理想）** → 相手の不安を取り除く最重要アクション
2. **定期連絡を絶対に続ける** → 案件はタイミング。月1回で確実に
3. **面談でお困りごとをヒアリングする** → 「外部パートナーに求めることは？」を必ず聞く
4. **品質チェックシート・報告書を提出する** → 「ここまでやってくれる人はいない」と差別化
5. **面談時の情報を定期連絡に活かす** → 繁忙期・困りごとを次のアクションに繋げる

### 価格交渉で使えるパターン
- 工数を細分化して「なぜこの金額か」を言語化する
- フルプランと削減プランの2パターンで提出する
- 「品質の担保のためご相談させてください」という前置きを使う
- スケジュール交渉はZoomでアポを取る（チャットより話しやすい）
- 相手の文章の「温度感」を読み解く（希望価格か、上限価格か）

### 継続受注に繋がる行動
- 報告書・品質チェックシートの提出
- 進捗報告を定期的に（相手を不安にさせない）
- よしなに対応（指示がない細かい部分も気が利く対応）
- 相手の手間を先回りして巻き取る
- 体調不良など雑談の言葉にも自分の言葉で反応する

### 断る時の注意点
- 断るだけじゃなく「なぜ断るか・できる代替案」を添える
- 「これ以上はできかねます」と正直に伝えつつ出来る範囲で提供する
- 丁寧に断ることで信頼が落ちない

### Rinaさんのディレクション案件に活かせること
- **面談時に必ず聞く**：「御社の繁忙期はいつですか？」→定期連絡に活かす
- **面談時に必ず聞く**：「外部パートナーに一番求めることは？」→提案の軸にする
- **見積もり提出時**：工数を細分化して金額の根拠を言語化する
- **初回案件**：品質チェックシートと報告書を必ず提出する
- **困りごとを察して提案**：「〇〇の部分、お手伝いできますが必要ですか？」
