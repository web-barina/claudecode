# STEP 7：ポジショニングマップ

## 入力

- `/tmp/research_{業界名}/02_competitor.json`（競合調査結果）
- `/tmp/research_{業界名}/03_3c.json`（3C分析結果）

## 目的

競合他社と自社（クライアント）の市場上での立ち位置を可視化する。
PDFテンプレートのバブルチャート形式に対応する。

## 軸の設定ロジック

業界に応じて最適な2軸を選ぶ。以下から選定（複数候補を出してベストを選ぶ）：

```
価格軸：低価格 ←→ 高価格
品質軸：標準品質 ←→ 高品質
専門性軸：総合型 ←→ 特化型
対象軸：個人向け ←→ 法人向け
規模軸：小規模対応 ←→ 大規模対応
スピード軸：じっくり型 ←→ スピード型
サポート軸：セルフ型 ←→ フルサポート型
地域軸：全国対応 ←→ 地域密着型
```

## 出力構造

```json
{
  "axis_x": {
    "label_left": "軸ラベル（左）",
    "label_right": "軸ラベル（右）",
    "description": "この軸を選んだ理由"
  },
  "axis_y": {
    "label_top": "軸ラベル（上）",
    "label_bottom": "軸ラベル（下）",
    "description": "この軸を選んだ理由"
  },
  "companies": [
    {
      "name": "企業名",
      "x": 0.7,
      "y": 0.8,
      "size": 1.2,
      "is_client": false,
      "note": "このポジションの根拠"
    }
  ],
  "client_position": {
    "name": "クライアント（自社）",
    "x": 0.85,
    "y": 0.75,
    "recommended_reason": "このポジションを推奨する理由（100文字）"
  },
  "map_insight": "マップ全体から読み取れる示唆（150文字）",
  "alternative_axes": [
    {
      "axis_x": "代替軸X案",
      "axis_y": "代替軸Y案",
      "when_to_use": "どんな場合にこの軸が有効か"
    }
  ]
}
```

### 座標の定義

- x, y ともに 0.0〜1.0 の範囲で指定
  - x: 0.0 = 左端、1.0 = 右端
  - y: 0.0 = 下端、1.0 = 上端
- size: バブルの大きさ（0.8〜2.0。市場シェア・規模感の目安）

## 保存先

```
/tmp/research_{業界名}/07_positioning.json
```

## 注意事項

- 軸は「差別化できる軸」を選ぶ（全社が同じ方向に固まる軸はNG）
- クライアントのポジションは「空白地帯・競合が少ないゾーン」を推奨する
- 代替軸案も1〜2セット必ず提示する
