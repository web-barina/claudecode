# STEP 2：競合調査

## 入力

- `業界名` / `サービス名`
- `指定競合企業リスト`（任意。パターンBの場合に引き継ぎ）
- `01_market.json`（STEP1の結果）

## 競合企業の選定方針

### 指定がない場合（パターンA）
- 大手・有名企業：2〜3社
- 中小企業・ニッチプレイヤー：3〜4社
- 合計6社を目安に選定

### 指定がある場合（パターンB）
- 指定された企業を優先してリストに含める
- 指定が6社未満の場合は自動補完する
- 指定が6社を超える場合はすべて調査する

## 検索クエリ

```
# 企業探索（パターンAの場合）
「{業界名} 会社 おすすめ 中小企業 日本」
「{業界名} 比較 企業 特徴」
「{サービス名} 会社一覧 料金」

# 各企業の詳細調査（各社ごとに実行）
「{企業名} サービス内容 特徴 強み」
「{企業名} 料金 価格」
「{企業名} ターゲット 顧客層」
```

## 調査項目（各社共通）

```json
{
  "competitors": [
    {
      "rank": 1,
      "company_name": "企業名・サービス名",
      "company_size": "大手 / 中小 / スタートアップ",
      "site_url": "https://...",
      "catchcopy": "キャッチコピー・タグライン",
      "services": "主なサービス内容（100文字程度）",
      "price_range": "価格帯（円表記）",
      "target_customer": "ターゲット顧客",
      "strengths": ["強み（3項目）"],
      "weaknesses": ["弱み・課題（2項目、推定可）"],
      "design_impression": "サイトデザインの印象（50文字程度）",
      "content_features": "コンテンツの特徴（50文字程度）",
      "promotion_methods": ["主な集客・PR方法"]
    }
  ],
  "selection_criteria": "競合選定基準の説明",
  "sources": ["参考URL"]
}
```

## 保存先

```
/tmp/research_{業界名}/02_competitor.json
```

## 注意事項

- URLは実在確認できるものだけ記載（不確かな場合は「公式サイトで確認」）
- 強み・弱みは事実ベース＋推定を混在させてよいが、推定は「（推定）」と明記
- 中小企業を3〜4社は必ず含める
