# STEP 5：ニーズ分析

## 入力

- `/tmp/research_{業界名}/01_market.json`（市場調査結果）
- `/tmp/research_{業界名}/03_3c.json`（3C分析結果）

## 目的

顧客が実際に検索しているキーワード・質問から「何を求めているか」を把握する。
PDFテンプレートの2シート（キーワード表・検索ワード質問表）に対応する。

## 検索クエリ

```
「{業界名} よくある質問」
「{サービス名} 選び方」
「{サービス名} 比較 どこがいい」
「{業界名} 悩み 課題」
「{サービス名} 料金 相場」（再確認）
「{業界名} 口コミ 評判」
```

## 出力構造

### シート1：キーワード分析

```json
{
  "keywords": [
    {
      "keyword": "キーワード",
      "search_volume_estimate": "月間検索ボリューム概算（例：1,000〜10,000）",
      "user_problem": "このキーワードを検索する人が抱えている課題",
      "site_application": "サイトへの活用案（ページ・コンテンツ提案）"
    }
  ]
}
```

キーワードは8〜12個抽出する。

### シート2：検索意図・質問分析

```json
{
  "search_intents": [
    {
      "search_query": "想定される検索ワード・フレーズ",
      "question_behind": "その検索の背景にある質問・不安",
      "information_source": "情報源URL（参考にしたページ）",
      "user_problem": "抱えている課題",
      "site_application": "サイトへの活用案"
    }
  ]
}
```

検索意図は6〜8個抽出する。

## 保存先

```
/tmp/research_{業界名}/05_needs.json
```

## 注意事項

- 検索ボリュームは正確な数値が取れない場合は概算・推定で記載し「（推定）」と明記
- 情報ソースURLは実際に参照したページのみ記載
- サイト活用案は「トップページに○○を掲載」「FAQ項目に追加」など具体的に
